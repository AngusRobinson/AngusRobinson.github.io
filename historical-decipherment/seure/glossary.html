Glossary

Letters in French and EnglishCharacter-by-character decryptionManuscript imagesKey
Homophonic
(Of a cipher) having multiple different symbols representing a single plaintext letter.
Nomenclator
A type of encryption that is a hybrid of a cipher (where text is encrypted letter by letter) and a code proper (where text is encrypted word by word).
Null
A sign used in a cipher that has no plaintext counterpart, used to create noise and put cryptanalysts off the scent.
Cancellation operator
A sign that instructs the recipient to ignore the previous character.
Hapax legomenon
(Usually) a word that is only found once in a corpus, such as Arepo.
Cleartext
Un-encrypted text found in a manuscript. Compare with plaintext.
Plaintext
The deciphered or not-yet-enciphered version of ciphertext.
Witness
An individual copy of a version of a text.
Monoalphabetic substitution cipher
The simplest form of cipher, in which a given letter is always represented by the same sign.
